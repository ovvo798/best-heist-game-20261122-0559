The Velvet Vault — an original top-down 2D heist game. A hooded thief crosses a guarded gallery past sweeping vision cones and security cameras to steal the Sunset Opal and slip out the getaway door before the alarm meter fills. Three patrol routes, three tools at a cost (smoke, coin toss, disguise), side gems and a time bonus, and a fair caught moment.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse.
